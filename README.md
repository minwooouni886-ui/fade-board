# fade-board
Fade is a hyperlocal bulletin board for communities that move fast and forget just as quickly — campus groups, neighborhood cafes, hobby clubs. Post a meet-up, a lost item, or a one-off event, and it burns out automatically after 24 hours. No stale listings, no bloated event pages, no sign-up funnels — just what's happening near you, right now.

Unlike heavyweight platforms like Meetup, Fade is built around a single constraint: everything expires. That constraint shapes the whole product — a clean card-grid feed with live countdown timers on every post, geo-radius search so you only see what's relevant to your area, and a backend that treats "cleanup" as a first-class feature instead of an afterthought.
